# excel-vba-charts

仓库只提供 **VBA 模块（`.bas`）** 与本文档，**不包含** `.xlsm`。在 Excel（以 Windows + VBA7 为主）中导入模块、按需改配置后运行宏即可。

---

## 一、使用方式（首次）

1. **新建或打开** 启用宏的工作簿（保存为 **`.xlsm`** 等）。
2. 按 **`Alt + F11`** 打开 VBA 编辑器，**文件 → 导入文件**，将仓库中下列模块全部导入为**标准模块**（建议顺序如下，一次性多选导入也可以）：
   - `modConfig.bas`
   - `modPivot.bas`
   - `modStaging.bas`
   - `modCharts.bas`
   - `modMain.bas`
3. 在工作簿里 **自己建好透视表**：数据源、行列值布局由你维护（见下文「透视布局要求」）。
4. 打开 **`modConfig.bas`**，把工作表名、透视表名、列/值字段名等改成与你工作簿 **完全一致**（见「需要自定义的参数」）。
5. **`Ctrl + S`** 保存工作簿。在 **信任中心** 中允许运行宏（按公司策略设置）。
6. 在 VBA 编辑器中打开 **`modMain`**，将光标放在 **`Run_Pipeline`** 过程内，按 **`F5`** 运行；或在 Excel 里通过 **宏** 列表运行 **`Run_Pipeline`**。

运行成功后：会 **刷新** 指定透视、**校验** 布局、在 **Staging** 工作表生成/覆盖 **`tblStage`** 宽表，并在 **图表** 工作表创建/替换名为 **`chtStagingStack`** 的堆叠柱形图。

---

## 二、使用方式（日常）

1. 在 Excel 中更新明细或透视数据源后，建议先在界面上 **右键透视 → 刷新**（宏里也会执行一次 `PivotCache.Refresh`，但本地先刷新可减少异常）。
2. 再次运行 **`Run_Pipeline`**。每次运行会 **重建** Staging 表与 **同名** 图表对象（旧图会被删掉再建），避免残留旧系列。

---

## 三、需要自定义的参数（`modConfig.bas`）

以下常量均在 **`modConfig`** 中修改；改完后保存工作簿再运行宏。**字符串须与 Excel 里工作表名、透视表名、字段源名一致**（区分是否改名）。

### 3.1 工作表与对象名（几乎总要核对）

| 常量 | 默认值 | 含义 |
|------|--------|------|
| **`PIVOT_SHEET`** | `透视` | 放置透视表的工作表 **名称**。 |
| **`PIVOT_TABLE_NAME`** | `ptSales` | 透视表 **名称**（右键透视表 →「数据透视表选项」或名称框中可见）。 |
| **`STAGING_SHEET`** | `Staging` | 输出宽表的工作表 **名称**（不存在时宏会创建）。 |
| **`STAGING_LIST`** | `tblStage` | Staging **`ListObject` 表名**。 |
| **`CHART_SHEET`** | `图表` | 放置嵌入图的工作表 **名称**（不存在时宏会创建）。 |
| **`CHART_OBJECT_NAME`** | `chtStagingStack` | 图表 **`ChartObject` 名称**（用于每次删除后重建，勿与工作簿内其他图重名）。 |

### 3.2 透视字段名（与数据源列名 / 透视字段源名一致）

| 常量 | 默认值 | 含义 |
|------|--------|------|
| **`COL_CUSTOMER`** | `客户` | 透视 **列区** 唯一字段的 **SourceName**（须与数据模型里列名一致）。 |
| **`COL_REVENUE`** | `收入` | 透视 **值区** 度量所基于字段的 **SourceName**；宏要求聚合为 **求和**。 |

行区可有 **多个**行字段，名称与顺序 **不必** 在 `modConfig` 里列出；Staging 表头会按透视行区顺序自动生成。

### 3.3 小额合并（可选）

| 常量 | 默认值 | 含义 |
|------|--------|------|
| **`ENABLE_CUSTOMER_MERGE`** | `True` | `True`：按规则把小额客户并进一列；`False`：只输出宽表，**无**合并列。 |
| **`MERGE_COL_CAPTION`** | `其他（客户小额）` | 合并列在表头显示的名称（最右一列）。 |
| **`MERGE_PROTECT_TOP_N`** | `10` | 每行按 **`|值|`** 从大到小，前 **N** 名客户 **永不** 并入合并列；第 N 名 **并列** 则并列者全部保护。 |
| **`MERGE_ABS_THRESHOLD`** | `500` | 绝对阈值 **A**：未受保护客户若 **`|v| < A`** 可并入合并列（与占比条件为 **或**）。 |
| **`MERGE_PCT`** | `0.01` | 占比 **p**（如 1%）：当 **T > 0** 且 **`|v| < T * p`** 时可并入（与绝对阈值为 **或**）。 |
| **`MERGE_PCT_DENOM`** | `AbsSum` | 本行 **T** 的定义，须为下列 **字符串之一**（与下方常量一致）：**`AbsSum`**（默认）、**`NetAbs`**、**`PosSum`**。也可写为与 `MERGE_DENOM_*` 相同的字面量。 |
| **`MERGE_DENOM_ABSSUM`** 等 | 固定字面量 | 一般 **不要改**；仅作 `MERGE_PCT_DENOM` 的取值参照。 |
| **`MERGE_TIE_BREAK`** | `NameAsc` | 与实现一致：并列时按 **客户名字典序**；当前代码未读取其它枚举，保留作文档说明即可。 |

### 3.4 图表外观

| 常量 | 默认值 | 含义 |
|------|--------|------|
| **`CHART_TITLE`** | `收入（堆叠）` | 图表标题文字。 |
| **`SHOW_DATA_LABELS`** | `False` | `True`：显示数据标签；`False`：关闭。 |
| **`CAT_LABEL_ANGLE`** | `-45` | 分类轴标签倾斜角度（度）。 |

## 四、透视布局要求

| 区域 | 要求 |
|------|------|
| **行** | **至少 1 个**行字段；顺序由你决定。宽表与图表：**从左到右** 与透视行区一致，**最左为最外层分类**，**最右一列对应最后一个行字段**（最细粒度），客户系列在该粒度上堆叠。 |
| **列** | **恰好 1 个**列字段，且 `SourceName` = **`COL_CUSTOMER`**（默认「客户」）。 |
| **值** | **恰好 1 个**度量，基于 **`COL_REVENUE`**（默认「收入」），且为 **求和**。 |

布局不符合时，**`Run_Pipeline`** 会报错中止（中文描述）。

---

## 五、Staging 与合并规则摘要

- **行键**：同一透视数据行上，各层行标签组合（内部用 Tab 拼接）；合并与 Top N 均在 **同一行键** 下、按各 **客户** 列计算。
- **`MERGE_PCT_DENOM`**：`AbsSum` 为 \(\sum |v|\)；`NetAbs` 为 \(|\sum v|\)；`PosSum` 为 \(\sum \max(v,0)\)。用于 **T** 后再与 **p** 比较；**T = 0** 时占比条件不成立，仍可能仅因 **`|v| < A`** 合并。
- 客户列顺序：全局按 **`|收入|` 之和** 从大到小，再按客户名字典序。

---

## 六、图表说明

- 类型：**堆叠柱形图**（`xlColumnStacked`），数据源为 **`tblStage` 整块区域**（含表头），`PlotBy:=xlColumns`。
- **前 N 列**（N = 行字段数）为 **多级分类轴**；右侧为客户（及合并列）系列。
- 数值轴：尽量使 **比例轴包含 0**，便于阅读正负堆叠。

---

## 七、排错摘要

| 现象 | 可能原因 |
|------|-----------|
| 未找到透视表 | `PIVOT_SHEET` / `PIVOT_TABLE_NAME` 与界面不一致 |
| 透视刷新失败 | 数据源无效、字段被删、缓存损坏 |
| 校验失败 | 列名/值字段名与 `COL_*` 不一致，或值区不是「求和」 |
| Staging 为空 | 无数据区，或 `PivotCell` 行项数与行字段数不一致 |
| 图表未更新 | `STAGING_SHEET` / `STAGING_LIST` 或 `CHART_*` 配置与界面不一致 |

---

## 八、Mac Excel

VBA、透视与图表在 Mac 上可能与 Windows 有差异；建议以 **Windows Excel** 为主验证。若 `PivotCell` 相关报错，请记录版本号。
