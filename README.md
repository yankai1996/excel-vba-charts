# excel-vba-charts

仓库只提供 **VBA 模块（`.bas`）** 与本文档，**不包含** `.xlsm`。在 Excel（以 Windows + VBA7 为主）中导入模块、按需改配置后运行宏即可。

**说明**：仓库内 **`.bas` 源码、注释、`MsgBox` 与 `Err.Raise` 提示均为英文**；仅 **本 README 使用中文**。工作表名、透视表名须与 **`modConfig`** 一致。字段名默认 **不强制**：`COL_CUSTOMER` / `COL_REVENUE` 留空则自动接受透视中的列字段与值字段；若需严格匹配，再填入与 **SourceName** 一致的字符串。堆叠系列来自 **列字段** 或 **行区最内层字段** 由 **`STACK_SERIES_FROM_LAST_ROW`** 决定（见第三节）。

---

## 一、使用方式（首次）

1. **新建或打开** 启用宏的工作簿（保存为 **`.xlsm`** 等）。
2. 按 **`Alt + F11`** 打开 VBA 编辑器，**文件 → 导入文件**，将仓库中下列模块全部导入为**标准模块**（建议顺序如下，一次性多选导入也可以）：
   - `modConfig.bas`
   - `modPivot.bas`
   - `modStaging.bas`（模块文件名仍为 **`modStaging`**，过程 **`BuildStagingWide`** 负责生成 **Target 目标宽表**）
   - `modCharts.bas`
   - `modMain.bas`
3. 在工作簿里 **自己建好透视表**：数据源、行列值布局由你维护（见下文「透视布局要求」）。
4. 打开 **`modConfig.bas`**，核对工作表名、透视表名、**`STACK_SERIES_FROM_LAST_ROW`** 是否与你的透视摆法一致；按需填写 **`COL_*`** 做严格字段名校验（见「需要自定义的参数」）。
5. **`Ctrl + S`** 保存工作簿。在 **信任中心** 中允许运行宏（按公司策略设置）。
6. 在 VBA 编辑器中打开 **`modMain`**，将光标放在 **`Run_Pipeline`** 过程内，按 **`F5`** 运行；或在 Excel 里通过 **宏** 列表运行 **`Run_Pipeline`**。

运行成功后：会 **刷新** 指定透视、**校验** 布局、在 **`TARGET_SHEET`**（默认 **`Target`**）上生成/覆盖 **`tblTarget`**，并在 **同一工作表** 上以嵌入 **`ChartObject`**（**`CHART_OBJECT_NAME`**，默认 **`chtTargetStack`**）**悬浮** 显示堆叠柱形图（图放在宽表 **右侧**，避免压住表体）。

---

## 二、使用方式（日常）

1. 在 Excel 中更新明细或透视数据源后，建议先在界面上 **右键透视 → 刷新**（宏里也会执行一次 `PivotCache.Refresh`，但本地先刷新可减少异常）。
2. 再次运行 **`Run_Pipeline`**。每次运行会 **重建** 目标宽表 **`tblTarget`**，并在 **同一张 `TARGET_SHEET` 工作表** 上 **删除并重建** 同名嵌入图，避免残留旧系列。

## 三、需要自定义的参数（`modConfig.bas`）

以下常量均在 **`modConfig`** 中修改；改完后保存工作簿再运行宏。**工作表名、透视表名** 须与 Excel 一致。字段 **`COL_*`** 非空时才做 **SourceName** 严格比对（不区分大小写）。

### 3.1 工作表与对象名（几乎总要核对）

| 常量 | 默认值 | 含义 |
|------|--------|------|
| **`PIVOT_SHEET`** | `Pivot` | 放置透视表的工作表 **名称**（须与界面一致）。中文示例：`透视`。 |
| **`PIVOT_TABLE_NAME`** | `ptSales` | 透视表 **名称**（右键透视表 →「数据透视表选项」或名称框中可见）。 |
| **`TARGET_SHEET`** | `Target` | 输出 **目标宽表** 的工作表 **名称**（不存在时宏会创建）。 |
| **`TARGET_LIST`** | `tblTarget` | 目标宽表 **`ListObject` 表名**。 |
| **`CHART_OBJECT_NAME`** | `chtTargetStack` | 与 **`tblTarget` 同页** 的嵌入图 **`ChartObject` 名称**（每次运行先删后建；勿与工作簿内其他图重名）。 |

### 3.2 堆叠系列来源（`STACK_SERIES_FROM_LAST_ROW`）

| 常量 | 默认值 | 含义 |
|------|--------|------|
| **`STACK_SERIES_FROM_LAST_ROW`** | `False` | **`False`（关）**：透视为 **N 个行字段 + 恰好 1 个列字段 + 1 个求和值**；**全部 N 个行字段** 作为横轴多级分类；**列区唯一字段** 的各取值 → 堆叠系列（列名可为「客户」或任意 **SourceName**）。**`True`（开）**：透视为 **N 个行字段 + 0 个列字段 + 1 个求和值**；**前 N−1 个行字段** 为横轴分类，**最后一个行字段** 的各取值 → 堆叠系列。开启时 **必须至少 2 个行字段**，否则校验报错。 |

### 3.3 透视字段名（可选严格校验）

| 常量 | 默认值 | 含义 |
|------|--------|------|
| **`COL_CUSTOMER`** | `""`（空） | **仅当 `STACK_SERIES_FROM_LAST_ROW = False` 时有效**：若 **非空**，校验列区唯一字段的 **SourceName** 必须与之相同（不区分大小写）；**空字符串** 表示不校验列名，任意列字段均可。中文示例：填 `客户` 可强制与界面一致。 |
| **`COL_REVENUE`** | `""`（空） | 若 **非空**，校验值区度量所基于字段的 **SourceName** 必须与之相同；**空字符串** 表示不校验值字段源名（仍须 **恰好 1 个值字段** 且为 **求和**）。中文示例：填 `收入`。 |
| **`BLANK_LABEL`** | `Other` | 空行/列标签、`(blank)` 等归并后的 **显示名**（勿与真实系列名冲突）。中文示例：`其他`。 |

行区可有 **多个**行字段；目标宽表左侧分类列的表头按透视 **行区顺序** 自动生成（开启「最后一行维 = 系列」时，**仅输出前 N−1 个行字段** 作为分类列）。**系列列** 的表头为透视中的系列标签（列字段或最内层行字段，取决于上表开关）。

### 3.4 小额合并（可选）

| 常量 | 默认值 | 含义 |
|------|--------|------|
| **`ENABLE_CUSTOMER_MERGE`** | `True` | `True`：按规则把小额系列并进一列；`False`：只输出宽表，**无**合并列。 |
| **`MERGE_COL_CAPTION`** | `Other (small amounts)` | 合并列在表头显示的名称（最右一列）。中文示例：`其他（小额）`。 |
| **`MERGE_PROTECT_TOP_N`** | `10` | 每行按 **`|值|`** 从大到小，前 **N** 个系列 **永不** 并入合并列；第 N 名 **并列** 则并列者全部保护。 |
| **`MERGE_ABS_THRESHOLD`** | `500` | 绝对阈值 **A**：未受保护系列若 **`|v| < A`** 可并入合并列（与占比条件为 **或**）。 |
| **`MERGE_PCT`** | `0.01` | 占比 **p**（如 1%）：当 **T > 0** 且 **`|v| < T * p`** 时可并入（与绝对阈值为 **或**）。 |
| **`MERGE_PCT_DENOM`** | `AbsSum` | 本行 **T** 的定义，须为下列 **字符串之一**（与下方常量一致）：**`AbsSum`**（默认）、**`NetAbs`**、**`PosSum`**。也可写为与 `MERGE_DENOM_*` 相同的字面量。 |
| **`MERGE_DENOM_ABSSUM`** 等 | 固定字面量 | 一般 **不要改**；仅作 `MERGE_PCT_DENOM` 的取值参照。 |
| **`MERGE_TIE_BREAK`** | `NameAsc` | 与实现一致：并列时按 **系列名字典序**；当前代码未读取其它枚举，保留作文档说明即可。 |

### 3.5 图表外观

| 常量 | 默认值 | 含义 |
|------|--------|------|
| **`CHART_TITLE`** | `Revenue (stacked)` | 图表标题文字。中文示例：`收入（堆叠）`。 |
| **`SHOW_DATA_LABELS`** | `False` | `True`：显示数据标签；`False`：关闭。 |
| **`CAT_LABEL_ANGLE`** | `-45` | 分类轴标签倾斜角度（度）。 |

## 四、透视布局要求

### 4.1 `STACK_SERIES_FROM_LAST_ROW = False`（默认）

| 区域 | 要求 |
|------|------|
| **行** | **至少 1 个**行字段；**全部**参与横轴多级分类（宽表左侧列数 = 行字段数）。 |
| **列** | **恰好 1 个**列字段；其各取值 → **堆叠系列**（`SourceName` 可为任意；若 **`COL_CUSTOMER`** 非空则须与之相同）。 |
| **值** | **恰好 1 个**度量，且为 **求和**；若 **`COL_REVENUE`** 非空则值字段所基于的 **SourceName** 须与之相同。 |

### 4.2 `STACK_SERIES_FROM_LAST_ROW = True`

| 区域 | 要求 |
|------|------|
| **行** | **至少 2 个**行字段：**前 N−1 个** → 横轴多级分类；**最后一个** → 堆叠系列（各取值一列）。 |
| **列** | **0 个**列字段（不得再放系列维到列区）。 |
| **值** | 同 **4.1**（**恰好 1 个求和**；可选 **`COL_REVENUE`** 严格校验）。 |

布局不符合时，**`Run_Pipeline`** 会报错中止（**错误描述为英文**）。

## 五、目标宽表与合并规则摘要

- **行键**：横轴分类各层标签组合（内部用 Tab 拼接）。**关**：键含 **全部 N 个行字段**；**开**：键含 **前 N−1 个行字段**。合并与 Top N 均在 **同一行键** 下、按各 **系列** 列计算。
- **`MERGE_PCT_DENOM`**：`AbsSum` 为 \(\sum |v|\)；`NetAbs` 为 \(|\sum v|\)；`PosSum` 为 \(\sum \max(v,0)\)。用于 **T** 后再与 **p** 比较；**T = 0** 时占比条件不成立，仍可能仅因 **`|v| < A`** 合并。
- 系列列顺序：全局按 **`|值|` 之和** 从大到小，再按系列名字典序。

## 六、图表说明

- 类型：**堆叠柱形图**（`xlColumnStacked`），数据源为 **`tblTarget` 整块区域**（含表头），`PlotBy:=xlColumns`。
- **位置**：图与 **`tblTarget`** 同在 **`TARGET_SHEET`**，为 **嵌入图**（悬浮于单元格之上）；默认放在 **列表区域右侧**，必要时可在 Excel 中手动拖动调整。
- **前 K 列**为 **多级分类轴**：**关** 时 **K = 行字段数 N**；**开** 时 **K = N−1**。右侧为堆叠 **系列**（及可选合并列）。
- 数值轴：尽量使 **比例轴包含 0**，便于阅读正负堆叠。

## 七、排错摘要

| 现象 | 可能原因 |
|------|-----------|
| 未找到透视表 | `PIVOT_SHEET` / `PIVOT_TABLE_NAME` 与界面不一致 |
| 透视刷新失败 | 数据源无效、字段被删、缓存损坏 |
| 校验失败 | 透视行列布局与 **`STACK_SERIES_FROM_LAST_ROW`** 不符；或 **`COL_*`** 非空但与透视 **SourceName** 不一致；或值区不是「求和」 |
| 目标宽表为空 | 无数据区，或 `PivotCell` 行项数与行字段数不一致 |
| 图表未更新 | `TARGET_SHEET` / `TARGET_LIST` 或 **`CHART_OBJECT_NAME`** 与界面不一致 |

## 八、Mac Excel

VBA、透视与图表在 Mac 上可能与 Windows 有差异；建议以 **Windows Excel** 为主验证。若 `PivotCell` 相关报错，请记录版本号。
