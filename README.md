# excel-vba-charts

仅含 **VBA 模块（`.bas`）** 与说明；仓库不提交 `.xlsm`。在 Windows Excel（VBA7）中新建工作簿，通过 **VBA 编辑器 → 文件 → 导入文件** 依次导入各 `.bas`，保存为启用宏的工作簿后使用。

## 流程概览

1. **`modData.BuildCleanTable`**：从 **`源数据`** 工作表上的 **`tblSource`** 读取明细，按表头映射清洗后写入 **`清洗`** / **`tblClean`**（列：`地区`、`年月`、`客户`、`收入`）。
2. **`modPivot.EnsurePivotAndRefresh`**：以 **`tblClean`** 为缓存源创建或重建 **`透视`** 工作表上的透视表 **`ptSales`**，刷新并校验布局（模式 B）。
3. **`modStaging.BuildStagingWide`**：从透视 **数据区** 汇总为宽表，可选按规则合并小额客户列，写入 **`Staging`** / **`tblStage`**。
4. **`modCharts.BuildOrRefreshChart`**：在 **`图表`** 工作表上创建/替换嵌入图 **`chtStagingStack`**（堆叠柱形），数据源为 **`tblStage`**。

入口宏：**`modMain.Run_Pipeline`**。

## 透视缓存与 `tblClean` 范围

每次运行 **`EnsurePivotAndRefresh`** 会按当前 **`tblClean.ListObject.Range`** 重建 **`PivotCache`**（`SourceData:=lo.Range`）。因此只要先执行 **`BuildCleanTable`** 把明细写回 **`tblClean`**（`WriteListBody` 会 **`Resize`** 列表以覆盖新行数），再刷新透视，缓存源与行数即保持一致。不要手动把透视源改到已失效的静态区域。

## 透视布局（模式 B，必须一致）

| 区域 | 字段 | 顺序 / 数量 |
|------|------|----------------|
| 行 | `地区`、`年月` | 必须先 `地区` 再 `年月`，共 2 个 |
| 列 | `客户` | 仅 1 个列字段 |
| 值 | `收入` | 求和，**恰好 1 个**值字段 |

行/列/值不符合时，宏会 **`MsgBox` 说明并中止**。透视表保留在工作簿中便于核对；Staging 数值来自透视数据区单元格（与刷新后的求和结果一致）。

## Staging 与小额合并（`modConfig`）

- **`ENABLE_CUSTOMER_MERGE`**：`False` 时只做宽表拷贝/整形，**不**写入合并列。
- **`MERGE_COL_CAPTION`**：合并列显示名（默认 `其他（客户小额）`），开启合并时该列一般在 **最右侧**。
- **Top N 不合并**：对每一行（同一 `地区`×`年月`），按各客户 **`|收入|` 从大到小** 排序；**前 N 名**（`MERGE_PROTECT_TOP_N`，默认 10）**永不**并入合并列。若第 N 名处 **`|收入|` 相同** 的客户多于一人，**并列者一律保护**（该行受保护人数可能多于 N）。`|v|` 相同时以 **客户名字典序** 作为二次排序（与 `modConfig` 中 **`MERGE_TIE_BREAK`** 语义一致；当前实现固定为字典序），保证稳定。
- **其余客户的合并条件（OR）**：对 **未受保护** 的客户 \(c\)，若 **`|v_c| < A`**（`MERGE_ABS_THRESHOLD`）**或者**（**`T > 0`** 且 **`|v_c| < T · p`**）（`MERGE_PCT`），则将该客户本行金额累加到合并列，并在宽表对应客户列写 **0**。若 **`T = 0`**，占比条件为假，仍可能仅因 **`|v_c| < A`** 被合并。
- **`T` 的计算（`MERGE_PCT_DENOM`，对整行全部客户列，含受保护者与未出现列的 0）**：
  - **`AbsSum`**（默认）：\(T = \sum_c |v_c|\)
  - **`NetAbs`**：\(T = \left|\sum_c v_c\right|\)
  - **`PosSum`**：\(T = \sum_c \max(v_c, 0)\)

在 **`NetAbs`** / **`PosSum`** 下，**`|v_c|/T`** 与各客户会计「构成比」不一定可加总为 100%；仅作「小额相对尺度」使用。

客户列顺序：先按 **全局 `|收入|` 之和** 从大到小排序客户，`|v|` 相同则 **客户名** 字典序（与 Top N 内二次排序一致）。

## 图表说明

- 类型：**堆叠柱形图**（`xlColumnStacked`），每个系列对应一列客户（及合并列，若存在）。
- 分类轴：前两列为 **`地区`、`年月`**，Excel 通常识别为 **两级分类**（外层地区、内层年月）；若你使用的版本显示不符合预期，可在 README 示意图语义下调整 **系列顺序** 或 **是否合并分类标签**（实现以 `SetSourceData` + `PlotBy:=xlColumns` 为准）。
- 数值轴：代码会尽量保证 **比例轴包含 0**（全正且自动最小值大于 0 时把最小值压到 0；全负时把最大值抬到 0），以便 **正值在零线上方、负值在零线下方** 的常规阅读。堆叠段的具体绘制顺序以 **Excel 默认堆叠行为** 为准。
- **`SHOW_DATA_LABELS`**：数据标签开关。
- **`CAT_LABEL_ANGLE`**：分类轴标签倾斜角（度）。

## 源表与表头

- **`tblSource`** 表头须能映射到：`地区`、`年月`、`客户`、`收入`（完全同名即可）。`modData` 中若存在列 **`区域`**，会视作 **`地区`** 的别名。
- 数值列支持简单去千分位、去货币符号；无法解析的数字按 **0**；文本空客户/地区/年月会写成 **`其他`**。完全空行跳过。

## 宏安全与导入

1. 将各 `.bas` 导入到工作簿标准模块。
2. 将工作簿保存为 **`.xlsm`**（或启用宏的格式）。
3. 在 **信任中心** 中允许运行宏（按贵司策略设置）。

## 排错摘要

| 现象 | 可能原因 |
|------|-----------|
| 提示源表缺列 | `tblSource` 表头与映射不一致 |
| 透视形状校验失败 | 行/列/值字段名或顺序与模式 B 不符 |
| Staging 为空 | 透视无数据区或未刷新 |
| 图表未更新 | `Staging` 表名、列表名与 `modConfig` 不一致 |

## Mac Excel

VBA 与透视/图表在 Mac 上可能存在差异；建议以 **Windows Excel** 为主验证。若 `PivotCell` 相关接口报错，请记录版本号并在 issue 中说明。
